- Database: PostgreSQL (Neon)
- Auth: JWT + RBAC

# Features
- Goal creation with weightage validation
- Manager approval workflow
- Quarterly check-ins with auto score calculation
- Analytics dashboard
- Escalation module
- Email notifications
